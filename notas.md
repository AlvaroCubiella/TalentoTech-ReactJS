# Ayuda de memoria

## Introduccion

#### Crear un repo en blanco

npm create vite@latest mi_proyecto

Framework: seleccionamos React
Variant: JavaScript
Linter: ESLint
Darle a si para confirmar e installar las dependencias

npm install

#### Instalar navegador de rutas

npm install react-router-dom

Ver en el archivo package.json que en la seccion

"dependencies": {
"react": "^19.2.8",
"react-dom": "^19.2.8",
"react-router-dom": "^7.18.4"
},

Se encuentre la libreria instalada correctamente.

Luego en main.jsx BrowserRouter envuelve a App

#### Correr Servidor

npm run dev
